# UA Radio

Професійний Android-додаток для прослуховування онлайн-радіо.

## Особливості

- 📱 Сучасний UI на Jetpack Compose
- ⏸️ Фонове відтворення (Media3 + ExoPlayer)
- 🔔 Нотифікація з керуванням
- ⭐ Обрані радіостанції
- 📊 Список радіо керується через адмінку (Supabase)
- 🌐 Публічний доступ (без реєстрації)

## Технології

- **Kotlin** + Jetpack Compose
- **Media3 (ExoPlayer)** — фонове аудіо
- **Supabase** — бекенд + адмінка
- Package: `ua.radio.online`

## Структура проекту

```
UA-Radio/
├── app/                    # Android додаток
├── admin/                  # Веб-адмінка (пізніше)
└── README.md
```
